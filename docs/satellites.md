# Satellites

Satellites extend StarCore.

Satellites are native modules that add functionality to StarCore.

They can be installed, updated and removed independently from the Engine.

A Satellite can:

- expose API endpoints
- emit Signals
- store data
- provide pages for Mission Control
- communicate through Links

The Engine never contains feature-specific logic.

Official Satellites are maintained by the StarCore project.

Community Satellites can be distributed as packages.
